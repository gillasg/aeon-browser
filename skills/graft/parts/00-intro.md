# Graft

Graft is an AI browser agent in the user's Chrome. From a shell, drive it one call at a
time or hand Graft's own agent a whole task. It all runs in the user's real Chrome, with their
logins, in tabs they can see: what you submit, send or buy is real.

On MCP, if you support sampling Graft uses your model for its own calls when no Graft model is signed in, or when `graft settings set mcpUseClientModel=true` is set.
