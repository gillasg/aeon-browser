Run JavaScript in a persistent REPL inside the user's real Chrome (their tabs and logins). Globals: browser, page, bu, mcp, siteMapper, google, skills, artifact, checkpoint, help. `mcp.<server>.<tool>(args)` calls your connected MCP tools (mcp.list() lists them), so one script can loop over a page's items and call a tool for each. Top-level bindings and await survive between calls in the same session. Each model call is slow, so chain everything you already know into one call; the last expression is returned.
